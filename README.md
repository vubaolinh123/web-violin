# Strad Plus

Website for Strad Plus — an acoustic formula that changes how wood resonates, developed by Nguyễn Xuân Huy.
Built with Next.js 16 (App Router), TypeScript, Tailwind CSS 4 and Framer Motion. English-language site aimed at
international distributors.

## Run

```bash
npm install
npm run dev      # http://localhost:3000
npm run build && npm start
```

## Where to edit content

| What | File |
| --- | --- |
| Contact details, nav, video id | `src/lib/constants.ts` |
| Products | `src/lib/data/products.ts` |
| Fields of application | `src/lib/data/applications.ts` |
| Artists & projects | `src/lib/data/projects.ts` |
| Founder biography | `src/app/founder/page.tsx` |

**Photographs:** put retouched images in `public/images/` and list their paths in a product's `images`
array. Until then the site shows an acoustic contour figure (`/art/*.svg`, generated by `src/lib/chladni.ts`).

**Contact form:** copy `.env.example` to `.env.local` and fill in the SMTP settings. Without them the form
asks visitors to email `contact@stradplus.com` directly.
