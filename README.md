# Strad Plus

Website for Strad Plus — an acoustic formula that changes how wood resonates, developed by Nguyễn Xuân Huy.
Built with Next.js 16 (App Router), TypeScript, Tailwind CSS 4 and Framer Motion. Aimed at international
distributors, in English and Vietnamese.

## Run

```bash
npm install
npm run dev      # http://localhost:3000
npm run build && npm start
```

## Languages

English is served at the plain URLs (`/technology`) and Vietnamese under `/vi` (`/vi/technology`). All pages live
in `src/app/[lang]/`; `src/proxy.ts` maps the plain URLs to English and sends visitors to Vietnamese when they
chose it with the EN / VI switch (remembered in a cookie) or, on a first visit, when their browser is set to
Vietnamese. Every text has an `en` and a `vi` version side by side, so edit both.

## Where to edit content

| What | File |
| --- | --- |
| Contact details, video id | `src/lib/constants.ts` |
| Menu, footer, form labels, buttons (both languages) | `src/lib/dictionary.ts` |
| Page text (both languages) | the `copy` object at the top of each `src/app/[lang]/**/page.tsx` |
| Products | `src/lib/data/products.ts` |
| Fields of application | `src/lib/data/applications.ts` |
| Artists & projects | `src/lib/data/projects.ts` |
| Founder biography | `src/app/[lang]/founder/page.tsx` |

**Photographs:** put retouched images in `public/images/` and list their paths in a product's `images`
array. Until then the site shows an acoustic contour figure (`/art/*.svg`, generated by `src/lib/chladni.ts`).

**Contact form:** copy `.env.example` to `.env.local` and fill in the SMTP settings. Without them the form
asks visitors to email `contact@stradplus.com` directly.

## Deploy on Vercel

Import the GitHub repository in Vercel (framework preset: Next.js, no other build settings needed), then under
**Settings → Environment Variables** add the variables from `.env.example`: `NEXT_PUBLIC_SITE_URL`,
`SMTP_HOST`, `SMTP_PORT`, `SMTP_USER`, `SMTP_PASS`, `CONTACT_FROM`, `CONTACT_TO`. Redeploy after changing them.

The contact form allows one request per visitor every 15 seconds. On Vercel this limit is per function
instance unless a Redis store is connected: **Storage → Create Database → Upstash for Redis** (free tier is
enough), connect it to the project and redeploy. Its `KV_REST_API_URL` / `KV_REST_API_TOKEN` variables are
picked up automatically.
